# nonag-shorts

A userscript for watching YouTube Shorts logged out without the sign-in and open-the-app nags.

To use it, install a userscript manager such as FireMonkey and open [nonag-shorts.user.js](https://raw.githubusercontent.com/arxodeus/nonag-shorts/main/nonag-shorts.user.js).

The script is written without ampersands, angle brackets, carets, asterisks, backslashes or backticks.

EUPL v1.2 or later.
